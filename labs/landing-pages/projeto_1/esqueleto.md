# Esqueleto do design para a landing page
## 1 bloco: 
    - Navbar
    - Hero

## 2 bloco:
    - Sobre nós
    - Resumo profissional/Sesumo do servico

## 3 bloco:
    - Cards dos seus servicos
    - Cards dos projetos

## 4 bloco:
    - Formulario para captar dados do usuario

## 5 bloco:
    - Footer

-- 
# Regras para o design:
- Nao deve criar blocos ou containers na tela vazios.
Por exemplo nao crie grid 2x3 aonde uma dessas colunas
esteja vazia. 

- O design da landing page nao pode passar a imagem
de estar faltando conteudo em algum espaco.

--

# Imagens para design 
Na raiz existe uma pasta screens, com imagens
para usar como referencia visual para o design 
da landing page.

Na raiz existe uma pasta assets para usar
dentro da landing page.
