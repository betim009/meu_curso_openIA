# Regra Principal

O PLANS.md é um documento vivo.

Isso significa:

* o documento deve ser atualizado durante a execução;
* novas descobertas podem gerar novas tarefas;
* melhorias podem gerar novos backlog;
* o plano pode evoluir conforme o projeto avança.

# Objetivo Principal

Construir uma landing page moderna, profissional, responsiva e visualmente equilibrada.

A landing page deve:

* transmitir profissionalismo;
* parecer completa;
* não possuir espaços vazios;
* não parecer um template genérico;
* utilizar os assets e screens disponíveis;
* ter boa hierarquia visual;
* funcionar bem no mobile e desktop.

# Prioridades

Sempre priorize:

1. Estrutura funcional
2. Responsividade
3. UX visual
4. Hierarquia visual
5. Conversão
6. Refinamentos

# Fluxo de Trabalho Obrigatório

Para cada etapa:

1. Ler o PLANS.md
2. Encontrar tarefas pendentes
3. Executar implementação
4. Validar resultado
5. Atualizar documentação
6. Gerar commit incremental
7. Continuar para próxima tarefa

# Comportamento Esperado

* Não pare após uma única tarefa.
* Não espere autorização após pequenas implementações.
* Não fique preso em detalhes mínimos.
* Não refatore desnecessariamente.
* Não recrie arquivos sem necessidade.
* Não remova funcionalidades existentes sem motivo.

# Responsividade

Validar constantemente:

* mobile;
* tablet;
* desktop.

Corrigir:

* espaçamentos;
* grids quebrados;
* sobreposição;
* alinhamentos;
* excesso de espaço vazio.

# Qualidade Visual

Evitar:

* containers vazios;
* grids incompletos;
* excesso de sombras;
* excesso de bordas;
* excesso de cores;
* aparência genérica;
* aparência improvisada.
