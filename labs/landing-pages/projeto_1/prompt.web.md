Vou esta enviando para voce um esqueleto de informacoes e um template de PLANS.md.

Esse esqueleto de informacoes tem o objetivo de ser usado por voce para gerar um PLANS.md para construir uma landing page como documento vivo a partir de um prompt enviado para o agente Codex. 

Se voce achar necessario mudar as informacoes dentro do esqueleto de dados para atingir real objetivo, faça. 

# Esqueleto do design para a landing page
## 1 bloco: 
    - Navbar
    - Hero

## 2 bloco:
    - Sobre nós
    - Resumo profissional/Sesumo do servico

## 3 bloco:
    - Cards dos seus servicos
    - Cards dos projetos

## 4 bloco:
    - Formulario para captar dados do usuario

## 5 bloco:
    - Footer

-- 
# Regras para o design:
- Nao deve criar blocos ou containers na tela vazios.
Por exemplo nao crie grid 2x3 aonde uma dessas colunas
esteja vazia. 

- O design da landing page nao pode passar a imagem
de estar faltando conteudo em algum espaco.

--
